# 20거래일 종목 순위 평가

기존 방향 확률·범위 전망과 독립된 오프라인 연구 도구다. 운영 모델, DB, 주문은 바꾸지 않는다.

```sh
cd batch
.venv/bin/python -m unittest test_rank_evaluation test_paper_monitor -v
.venv/bin/python rank_evaluation.py
.venv/bin/python paper_monitor.py --record
.venv/bin/python publish_rank_report.py
```

이후 새 일봉을 수집하면 `paper_monitor.py`를 다시 실행해 고정한 후보의 실제 이후 결과를 계산한다. 자동 실행은 등록하지 않는다. 새 실험은 `--record`를 명시해야 별도 고정하며, 같은 실험은 최초 발행 시각을 덮어쓰지 않는다. 발행 시각보다 이후인 첫 실제 정규장 시가만 모의 진입에 사용할 수 있다. 가격 누락·미해결 분사·분할이 있으면 결과를 숨겨 좋은 종목만 남기지 않고 `needs_price_review`로 보류한다.

## 고정 실험 규칙

- 국내/미국 개별 주식 별도. ETF는 시장 비교에만 사용.
- 같은 날짜에 지표가 모두 준비된 공통 종목 집합. 신호 당일 거래량 0인 종목은 제외.
- 당일 종가까지 신호 → 다음 시장 거래일 시가 진입 → 20시장거래일마다 상위 20개 동일비중 교체.
- 예측 라벨은 다음 날 시가부터 20거래일 뒤 시가까지의 수익률을 같은 날 시장 안에서 순위화.
- 현재 기술 점수 재현값/12-1개월 모멘텀/고정 규제 선형모델 비교. 기술 점수의 RS20 지수는 KODEX200/SPY 대용치이며 공통 스트레스 감쇠 전 점수다.
- 선형모델은 12개 순위 특징, 규제 0.1 고정. 분기마다 과거로만 학습. 학습 라벨 종료일이 평가 분기 시작일보다 엄격히 이전인 자료만 사용. 학습 최소 252일.
- 기본 비용은 매수 10bp, 매도 20bp(실제 요율 아님), 보수 조건 2배. `--buy-bps`, `--sell-bps`로 변경 가능. 실제 매매 대금에만 차감하며 비중 유지에는 재차 부과하지 않음.
- 실제 보유 주식 수와 현금을 유지하고 매일 종가 평가. 거래 정지/시가 누락에는 약정을 만들지 않고 보유·현금을 유지. 마지막 평가일 시가에 청산(불가 시 진단).
- 시작일 0/5/10/15일 이동은 민감도 검증이며 독립 검증 4개가 아님.
- 비교 기준: 동일 종목 집합의 동일비중, 시장 ETF. 시장 대비 지표는 동일 기간 누적 수익률 차이(%p).
- 최대 낙폭은 최초 현금 1을 포함한 일별 순자산 곡선. 연환산 회전율은 (매수+매도 대금)/평균순자산/연수이며 한 방향 회전율과 다름.

## 산출물

`logs/rank-evaluation/`에 데이터·설정·소스 버전 지문, 평가 패널, 분기별 학습 구간, 표본 외 예측, 일별 자산 CSV, 거래·수수료 CSV, 시작일/비용별 결과, 가격 진단과 보고서를 기록한다. 캐시는 원본 가격/메타데이터/코드/라이브러리 버전/설정의 지문이 일치할 때만 재사용한다. 신뢰된 로컬 pickle만 읽는다.

실제 보고서는 공개 Git 저장소에 커밋하지 않는다. `publish_rank_report.py`로 비공개 Storage 버킷 `owner-model-research`에 요약만 올리고 서비스 키로 읽어 검증한다. 공개 URL도 거부되는지 검사한다. 로컬 JSON은 gitignore된 logs/에 둔다. `--web-report`는 선택적인 로컬 내보내기이며 공유 저장소에 추가하면 안 된다. `/research`는 인증 서버가 확인한 지정 계정만 서버에서 허용한다. 다른 계정은 404 처리하며 메뉴·종목 전망도 표시하지 않는다. 표시용 쿠키·수정 가능한 프로필 전화번호는 권한에 사용하지 않는다. Storage 보고서는 계정 확인 후 서버 모듈에서만 불러오며 공개 API·공개 URL·서명 URL을 만들지 않는다.

## 채택은 별도 판단

`research_only`로 고정하고 자동 활성화하지 않는다. 비용 차감 초과수익, 최대 낙폭, 회전율, 분기별 일관성, 시작일과 비용 민감도, 가격 진단을 함께 본다. 과거 기간을 이미 여러 번 시험했고 2026-10-24 이전 구성종목·상장폐지 이력도 없으므로 현재 결과로 채택하지 않는다. 최초 모의 후보를 고정하고 이후 미사용 데이터로 확인해야 한다. 낙폭·회전율 허용 한도는 다음 모델 선택 전에 결정한다.

가격수익률이며 배당 현금/세법/환전/최소매매단위/시장충격을 완전히 재현하지 않는다. 가격 단절을 전후로 특징·학습 라벨을 분리하되 보유 중 발생하면 별도 경고하고 검토 전 채택 보류한다.

웹 접근 검사: `cd web && node scripts/check-model-access.mjs`. 지정 Auth 계정 ID만 허용하며 다른 계정·미로그인·인증 오류 때는 보고서를 불러오지 않는지 확인한다.
